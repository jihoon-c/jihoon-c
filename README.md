Windows C++ 기반 장비 통신, 언리얼 VR 시뮬레이터, 멀티스레딩에 관심이 있습니다.

## Featured Projects

### [TraceMotive — Debug Pathfinder for Unreal](https://github.com/jihoon-c/TraceMotive)

언리얼 에디터에서 디버깅 근거를 빠르게 찾도록 돕는 C++ 플러그인입니다.

- Blueprint 심볼 참조와 에셋 사용 위치 탐색
- PIE 인스턴스의 변수 값 추적과 액터 간 충돌 설정 분석
- 대규모 프로젝트를 고려한 time-sliced scan, 비동기 로딩, 취소 및 결과 제한

### [DeviceLink Studio](https://github.com/jihoon-c/DeviceLink-Studio/tree/develop)

Unreal 가상 EO/IR 장비와 Windows MFC 관제 콘솔을 TCP로 연결한 C++20 기반 SILS-like 테스트베드입니다.

- Binary framing, CRC16, stream parsing과 자동 재접속
- 장애 주입, Telemetry·알람 이력, Record & Replay
- 시나리오 자동 실행과 PASS/FAIL 시험 보고서 생성

### [TransactionScaleLab](https://github.com/jihoon-c/TransactionScaleLab)

대용량 트랜잭션 환경의 조회 지연, DB 부하 집중, 동시성 충돌을 재현하고 개선하는 백엔드 실험 프로젝트입니다.

- 100만 건 데이터에서 covering index와 cursor pagination 비교
- PostgreSQL Primary/Replica 자동 Read/Write 라우팅과 복제 상태 관측
- Redis 분산 락, DB 비관적 락, 동시성 통합 테스트와 실시간 대시보드

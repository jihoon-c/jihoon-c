# 안녕하세요, jihoon-c입니다 👋

Windows C++ 기반 장비 통신, 시뮬레이터, 멀티스레딩과 시험 자동화에 관심이 있습니다.  
현재는 실제 하드웨어 없이도 통신 장애와 복구 절차를 반복 검증할 수 있는 가상 장비 통합 환경을 개발하고 있습니다.

## Featured Project

### [DeviceLink Studio](https://github.com/jihoon-c/DeviceLink-Studio)

Unreal 가상 EO/IR 장비와 Windows MFC 관제 콘솔을 TCP로 연결한 C++20 장비 통신·자동 시험 프로젝트입니다.

- TCP 연결, 송수신 worker, 자동 재접속과 안전 종료
- Binary framing, CRC16, stream parsing과 손상 frame 복구
- Telemetry heartbeat, 통신 알람, SQLite 이력
- Fault injection, Record & Replay, scenario와 시험 보고서
- Unreal 가상 장비를 이용한 SILS-like 통합 검증
